# Outcome

实现 D4：在现有单表对照工作台中看清记录缺失与字段差异，并明确范围和扫描完整性，全程只读。

# Scope

沿用 docs/design/roadmap.md 的 D4、overview.md 的 F13/F14 与相关 F22、数据规则第 6 节和 interaction-design.md 数据页面。复用现有连接、库表配对、Ant Design、Qt 与 QMYSQL。

可靠主键/非空唯一键及复合键、同名兼容字段选择、共享结构化筛选、后端分批读取与比较、前端分页、精确类型值、按键定位、记录详情、长值按需查看与复制、停止和完整性状态。无可靠键时仅分别浏览。

# Non-goals

D5/D6 数据写入和同步计划、无键猜测匹配、任意 SQL/转换脚本、异名字段自动映射、全局同一时刻快照、正式发行和未实测的性能承诺。

# Acceptance examples

- A1：数据页复用连接和库表配对，进入不自动扫描；换连接、表、设置或执行结构变更后旧结果失效，迟到响应不能覆盖新上下文。
- A2：两端可验证的主键、非空唯一键和复合键可建议与选择；不可靠键说明原因，无键表仅分别分页浏览，不按行号生成匹配结论。
- A3：默认同名兼容字段，可选择参与字段；共享 AND 条件参数化应用两端，原生端拒绝非法字段、操作符和值，不兼容项明确列出。
- A4：跨批次识别相同、不同、仅左、仅右；两端完整扫描才给出最终计数和完整结论。双端空、单端空、缺表、权限失败、断线和取消不混淆。
- A5：BIGINT、DECIMAL、NULL、空串、0、二进制、时间和 JSON 按类型无损处理；长值差异不因显示截断或哈希相等被漏报，不支持值明确提示。
- A6：结果分页，支持状态过滤、完整键定位、变化字段查看；详情左右对齐，长值按需加载，复制原值，搜索无匹配不显示两端一致。
- A7：后台分批扫描，真实扫描量和阶段，可停止与回收任务，界面可操作；前端不接收整表，失效/关闭清理临时结果，普通配置和日志不保存业务行或密码。
- A8：原生/前端回归、隔离 MySQL 和真实 Qt WebEngine 检查覆盖只读比对及 D1–D3 相关行为；记录实际样本、环境与未运行平台项。

# Constraints and invariants

MySQL 8.0+ 为目标，兼容证据以实测为准。两端分别标读取时间，不宣称跨服务器瞬时一致。分页、中断不代表完整扫描。精确数不转 JavaScript Number，文本不随意 trim 或忽略大小写。

测试只用脚本创建的独立本地临时数据库，不连接已有业务库。复用工具链，不升级全局工具。Windows 10/macOS 15 实机沿用 docs/development/platform-validation-pending.md，不能以本机验证替代。

# Decisions

- 用户请求开始 D4；创建 data-compare，干净工作区采用 current/main，完整 Shape 待确认。
- 一个 Native change：键、读取、比较、详情共用任务上下文，拆分无独立交付价值，不用 Supervisor。
- 首版共享 AND 筛选：等于、不等于、大小比较、IS NULL、IS NOT NULL，按类型开放合法操作符。无条件表示全表，启动前显示范围。
- 同名字段映射，不猜异名，不做转换；不兼容类型与键排序语义明确受限，不静默跳过后宣称整表相同。
- 键定位使用完整键；无键浏览不承诺稳定排序或跨页身份。
- 如需后端临时结果，限定当前任务并清理，不恢复为有效旧结论。
