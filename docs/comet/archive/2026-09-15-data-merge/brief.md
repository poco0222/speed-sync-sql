# Outcome

完成 D5 data-merge：在已有 D4 精确数据比对上，提供可预览、可确认、可停止、可复核的补齐与合并更新。

# Scope

依据 docs/design/roadmap.md 的 D5、overview.md 的 F15/F16/F18/F19/F20/F22 与第 6 节、interaction-design.md 的数据页和执行流程。沿用 PRODUCT.md 技术栈及既有 D3/D4 行为。

- 左→右或右→左单端写入；默认补齐，另提供合并更新。
- 完整比对后，对全部符合当前共享条件的差异生成计划；更新字段可选，键不更新。
- 分页操作预览、参数化 SQL 与样例、写入前校验、事务分批、停止、执行记录与重新比对。
- 支持可证明兼容的 MySQL InnoDB 表；不支持或无法证明安全的结构给出原因并阻止执行。

# Non-goals

D6 删除/完全对齐、REPLACE、无键复制、自动修改结构、任意 SQL 或转换脚本、持续同步、全局回滚、自动重试未知提交、生产库操作、D7 打包及双平台发行承诺。

# Acceptance examples

- A1：左右两个方向均能生成计划；默认补齐只插入缺失键，合并另更新同键的选定差异字段，键值和目标独有记录始终保留；非选定字段不被更新。
- A2：未完整扫描、无可靠键、字段/必填列/生成列/唯一约束不兼容或非 InnoDB 时明确阻止写入；可空列、默认值、自增和生成列按真实目标定义处理，不通过隐式截断或重置规避错误。
- A3：预览显示目标别名/库表、方向、模式、键、范围、字段、读取时间、增改计数、分页操作与参数化语句样例；仅预览不写库，一次摘要确认才执行，重复请求不重复执行。
- A4：写入前核对结构和目标预期旧值；目标已改、已删、缺失键已出现或范围外同键均报告冲突，当前批次回滚并停止后续批次；不覆盖并发变化，不自动重试。
- A5：多批事务中仅已确认提交的批次计入成功；SQL 失败回滚当前批次，保留先前提交；停止在可控边界生效，未执行项可区分；提交响应丢失或进程异常标结果待核实。
- A6：BIGINT、DECIMAL、NULL、空串、二进制、微秒时间和长值写入保真；使用完整缓存值、正确标识符与参数绑定；触发器及外键保持启用，预览披露可见副作用，约束失败可解释。
- A7：连接/表/方向/字段/范围变化及结构执行使旧计划失效；执行期间锁定上下文并保护退出；记录保存摘要、批次及错误状态而非整表业务值，重启不恢复可执行计划，未完成记录标待核实。
- A8：执行后可按原上下文重新比对，分别显示执行结果和复核差异；真实 Qt 数据页完成预览、确认、执行、停止/失败反馈和记录查看，既有 D3/D4 回归检查通过。

# Constraints and invariants

一次计划只写入一端。无 DELETE、REPLACE、关闭外键/触发器或跨表自动修复。每批提交不是整任务原子提交。读取基准是预览对应的完整扫描快照，不承诺源端随后变化会自动加入计划，也不承诺双端全局同一时刻一致。

复用本地 Qt/MySQL 与既有测试工具；真实写入验证只使用测试自行创建的独立临时 MySQL。凭据不进入普通配置、日志或报告，临时业务值随任务回收。

# Decisions

- 沿用 Comet Native，当前干净 main 工作区。用户已于 2026-09-15 明确确认完整 Shape，Runtime 已进入 Build。
- 单一紧密关联 change：计划、执行、生命周期和 UI 共同构成受控写入链，不拆 Supervisor 子任务。
- 默认补齐；执行范围为全部符合当前条件的差异，分页和搜索不缩小写入范围。更新字段使用显式子集，修改设置后重新比对/预览。
- 自动写入限定 InnoDB；不可证明兼容的情况保守阻止，原因可见。
- 批次内全成或全回滚；任一冲突/错误停止后续批次。先前提交保留，不提供跳过冲突继续覆盖。
- 延续既有 Ant Design 数据工作台与执行记录；Windows/最低 macOS 实机缺口如实记录。

# Verification expectations

复用 C++ 单元/生命周期、前端测试、macOS 构建、独立临时 MySQL 与真实 Qt WebEngine。新增多批次、并发冲突、范围外键、精确值、失败/停止/未知提交的针对性验证。Builder 候选独立只读复核后由 Runtime 检查与独立 Verifier 验收。未执行平台检查标 NOT RUN，不作为已通过证据。
