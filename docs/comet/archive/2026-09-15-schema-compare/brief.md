# Outcome

交付 D2：在真实 Qt 桌面中选择左右 MySQL 库表，读取结构并显示可信的单表差异，支持原始定义查看和差异摘要导出。

# Scope

沿用 PRODUCT.md、docs/design/overview.md、docs/design/interaction-design.md、docs/design/roadmap.md 与已归档 desktop-foundation 规格。

- F03：数据库/表清单、搜索、刷新、同名配对、不同名手动配对及单端缺表。
- F04：记住最近连接组合对应的库表选择与面板尺寸；重启不自动查询，不恢复旧比对结论。
- F05-F08：字段、索引、主键/外键/CHECK、表属性与触发器的结构化读取和比较。
- F09：分类浏览、左右属性对照、对象搜索、只看差异、原始 DDL、完整差异摘要导出。
- F22 的 D2 部分：真实加载/取消/超时/失败状态，过期结果隔离与重新读取。

# Non-goals

- D3-D7 的同步 SQL 生成/执行、方向与写入选区、数据行读取/比较/写入、执行记录、发行安装包。
- 整库扫描、自动猜测重命名、视图/存储过程/函数/事件的结构化比较，分区与未知特殊选项的语义等价判断。
- 不修改用户现有数据库，不使用现有业务库做开发测试，不新增全局工具或升级技术栈。

# Acceptance examples

- A1：显式读取两端可见数据库与表清单，支持搜索、刷新、同名配对和不同名手动配对；仅清单读取不标相同/不同。可见性不足不判缺表，确证缺失才显示仅左/仅右。
- A2：实际 MySQL 样本及单元样本覆盖字段名称/顺序/类型/精度/NULL/默认值/字符集/排序规则/注释/自增/生成表达式/可见性，以及主键、普通/唯一/全文/空间/函数/不可见索引属性；字符串与表达式不被粗暴规范化，当前自增计数不产生结构差异。
- A3：外键列/引用关系/动作、CHECK 表达式/启用状态、表引擎/字符集/排序规则/注释/行格式，以及触发器事件/时机/顺序/正文/DEFINER/sql_mode/字符集上下文可对照；分区、未知选项及无法安全解释的特性显示定义与不支持原因。
- A4：相同、不同、仅左、仅右、未读取、读取失败、不支持有明确文字；权限不足、空结果、缺失、取消、部分失败分别测试。只有全部必需类别完整且受支持才可宣称结构相同，部分可读结果可查看但不假报全表一致。
- A5：真实桌面完成选库表、比对、分类/搜索/只看差异、长定义左右查看与复制；原始 DDL 文本不同不直接决定结构不同。浅/深主题、标准/紧凑密度、1440×900、1280×800、约 1024px 宽及缩放下，上下文和关键操作可达。
- A6：后台读取保持窗口响应，取消与超时释放任务。换连接/编辑或删除连接/换库表/刷新后旧请求不覆盖新上下文；重启恢复选择和尺寸但不联网或恢复旧结果；旧配置正常加载，保存失败可见。
- A7：原生保存对话框导出 JSON 完整差异摘要，含左右别名/库表、读取时间、版本、完整对象状态/属性差异和未完成原因，不随界面筛选遗漏；不含密码、连接串、主机和登录账号。取消不报错，保存失败反馈；过期结果禁止导出为当前结果。
- A8：D1 回归与新增比对检查、前端类型检查/构建、原生构建、隔离本地 MySQL 集成和真实桌面检查有通过证据；应用读取路径不执行 DDL/DML、不读取业务行。无环境的目标系统/版本特性明确记录 NOT RUN，不用模拟结果冒充实测。

# Constraints and invariants

- 沿用 Qt 6.10.2、C++20、React 19.2.7、TypeScript 6.0.3、Ant Design 6.4.5；原生端负责数据库与比较，React 负责交互。
- 继承 D1 凭据/TLS、受信本地桥接、线程归属、配置持久化和退出任务保护；密码不进普通存储或日志。
- 面向 MySQL 8.0+，按实际版本/元数据能力判断，不承诺所有未来版本兼容。
- 两端读取时间分别记录，不承诺统一快照；检测到定义变化时标需重新读取。

# Decisions

- 用户指定沿用当前目录；D1 已归档，D2 使用 main，不创建分支或 worktree。
- 一个普通 Native change：读取、比较与界面共享任务上下文和结果契约，拆分增加交叉修改，不采用 Supervisor Change。
- 继承布局 B：顶部双端连接、左侧表导航、主区单一表格左右分组列；D2 隐藏数据与同步操作。
- 导出采用 JSON，复用原生保存能力；摘要与界面过滤独立，原始 DDL 在详情单独复制。
- 分区/未知特殊选项保留原定义并标结构化比较不支持，不猜测等价。
- 继承 D1 归档决定：Windows 10/macOS 15 实机验证仍为后续待办，不将本机通过扩大为目标系统通过。
