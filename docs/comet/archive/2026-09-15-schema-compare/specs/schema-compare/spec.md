# D2 单表结构比对

## Purpose

用真实 MySQL 元数据核对左右单表结构。覆盖 F03-F09 与 F22 读取状态，继承 D1 连接、凭据、Qt 桌面和设置能力，不包含数据库写入。

## 库表选择与最近工作

- 左右位置固定，各端显示连接别名、数据库及表；选择数据库不改写连接配置中的默认数据库。
- 用户显式加载清单或开始比对。启动、恢复布局、切换页面不自动联网；默认数据库可预填，仍需读取确认。
- 数据库/表清单支持刷新，表名支持搜索；只展示账户可见范围，视图明确标为本阶段不支持。
- 默认同名配对，允许明确手动配对不同名表，不猜测重命名。仅加载清单的表标未比对，不扫描整库。
- 权限过滤的清单中没有对象不等于不存在；允许明确输入对端表名并验证。无法区分权限与不存在时显示无法确认；只有确证缺失才标仅左/仅右。
- 记忆最近连接组合对应的库表配对和导航宽度，提供布局重置。连接变更/删除后校验选择，不套用其他连接的结果。
- 重启不恢复旧比对结论；新增可选配置字段兼容 D1。复用原子保存，保存失败可见，损坏配置不覆盖。

## 读取与结果契约

- 原生端通过 QMYSQL 在后台读取 INFORMATION_SCHEMA、SHOW CREATE 等只读元数据；连接建立、使用、释放在同一工作线程内，保留进程隔离、凭据与 TLS 规则。
- 查询值参数化；标识符安全引用，不把库表名当 SQL 片段。桥接不接受任意 SQL，不提供 DDL/DML 或业务数据行读取。
- 请求绑定连接 ID/修订、库表配对与代次。取消、刷新、换选择、编辑/删除连接使旧请求失效，迟到结果不得更新当前视图或导出结果。
- 各端记录版本、开始/结束时间；各类别记录读取状态与原因，允许保留可靠的部分结果。
- 对可能静默隐藏的触发器等元数据验证完整可见性；无法确认时标权限/完整性受限，零行不能自动解释为空集合。
- 比较前后检查原始定义等可观察结构标识，检测到变化则要求重新读取；不承诺检测全部并发变化或两端统一快照。
- 显示阶段与真实耗时，不伪造百分比。取消后停止消费结果并回收进程；连接/查询超时有界，取消与失败分别显示。退出沿用运行任务提示和回收。

## 结构化属性

| 类别 | 比较内容 |
| --- | --- |
| 字段 | 名称、顺序、完整类型及长度/精度、NULL、默认值种类与值、字符集/排序规则、注释、自增、生成表达式/存储方式、可见性 |
| 索引 | 名称、主键/唯一/普通/全文/空间类型、方法、列/表达式顺序、前缀长度、升降序、可见性、注释 |
| 外键 | 名称、本表列顺序、被引用库/表/列顺序、更新/删除动作 |
| CHECK | 名称、表达式、ENFORCED 状态 |
| 表属性 | 引擎、字符集、排序规则、注释、行格式；分区和未知选项保留原定义并标受限 |
| 触发器 | 名称、事件、时机、顺序、正文、DEFINER、sql_mode、character_set_client、collation_connection、database_collation |

- 原生端生成左右值、差异属性与状态，前端不以截断显示值比较。
- 默认值区分 SQL NULL、字符串、数值与表达式等可观察语义，精度值无损传递；不能可靠解释的特性标不支持。
- 根据实际版本/字段能力识别 CHECK、函数索引、不可见字段/索引等；缺失元数据字段不能补空后判一致。
- 分区、未知特殊选项与不能解释的特性保留定义和原因；已支持类别仍可查看，但不宣称全表相同。

## 匹配与规范化

- 按实际 MySQL 标识符规则匹配，读取 lower_case_table_names 等上下文；跨端规则歧义时要求明确配对或标受限，不统一转小写。
- 同名字段/索引/触发器逐项比较，不猜测重命名。不同名表手动配对时，表名本身只作上下文。
- 本表所属库名及明确指向配对表自身的引用可按配对身份处理；外部库/表引用及触发器/表达式限定名保持真实含义，不全文替换。
- 忽略 AUTO_INCREMENT 当前计数、统计量、创建/更新时间；字段自增标记仍比较。
- 原始 DDL 保留原文；只规范化有充分语义依据的格式差异，不粗暴去除字符串/表达式空格或统一大小写。不确定项保守标受限。
- 原始 DDL 文本差异用于详情，不替代结构化比较，不直接使无关格式成为结构差异。

## 状态与浏览

- 对象状态为相同、不同、仅左、仅右、未读取、读取失败、不支持；取消单独显示任务状态，未完成类别保持未读取。
- 总体摘要明确完整性。必需类别全部完整、可比较且无差异才显示结构相同；零差异不能掩盖失败或不支持。
- 确证单端缺表则展示存在端结构及缺失端提示；两端均无表提示配对无效，不显示空表相同。
- 沿用布局 B：顶部双端上下文、左侧表导航、主区 Tabs 和单一 Table 的左右分组列；字段、索引、约束、触发器、表属性、原始定义均可访问。
- 支持对象搜索与只看差异；过滤仍保留未读取/失败/不支持项。搜索无匹配不能显示两端相同；摘要计数来自完整结果，可见数量另标。
- 复杂属性可展开，长表/触发器 DDL 可左右查看、复制，保留完整库表身份和原文，不丢失截断内容。
- 沿用 Ant Design 主题/密度与标准组件，状态有文字；窄窗口可收起导航、内容独立滚动或逐属性展开，关键操作可达。
- 主操作为开始/刷新比对；隐藏同步方向、写入选区、SQL 生成/执行、数据模式和未实现记录。

## 导出

- 用户主动通过原生保存对话框导出 UTF-8 JSON。包含格式版本、生成时间、左右别名/库表/版本/读取时间、总体完整性、分类状态、对象属性差异和未完成原因。
- 完整摘要不受搜索/页签/只看差异影响；部分结果可导出但须明确不完整与原因。
- 不含密码、完整连接串、主机/登录账号。DEFINER 属于对象结构属性，不误当登录凭据剔除；原始 DDL 在详情查看/复制，摘要不默认附带完整原文。
- 未比对、读取中或已过期结果不可作为当前结果导出；取消保存不报错，写入失败保留结果并反馈。

## 验证与边界

验收统一使用 brief.md A1-A8，不重复生成同义场景。规则测试、隔离 MySQL 样本、异步/桥接检查、前端测试与真实桌面检查共同取证，覆盖正常、不同、缺失、权限过滤、失败、取消、不支持及 D1 回归。

样本 DDL/DML 和账号授权仅用于临时本地测试实例准备/清理；产品只读，不修改现有业务库。沿用锁定工具，不升级全局依赖。

继承 D1 平台待办：Windows 10/macOS 15 未实测保持 NOT RUN，本机通过不代表目标平台通过；正式平台支持声明/发行前补齐。Builder 复核与新的只读 Verifier 独立验收按 Runtime 执行。
