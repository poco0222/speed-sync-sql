# Outcome

完成 D3：在 D2 单表比对上实现方向与选区、SQL 预览、原结构保存、执行、复核及本地记录。

# Scope

承接 docs/design/roadmap.md D3，overview.md F10-F12、F20、F22 与 interaction-design.md 布局 B。

- 左右双向、单次只写一端；选中对象同步、受支持范围的整表结构对齐、确证目标缺表时建表。
- 普通字段、普通/唯一/主键/全文/空间索引、表注释/默认字符集/排序规则/行格式、基本触发器。
- 外键、CHECK、生成列、函数索引、分区、引擎转换及未知特性仅展示；相关依赖无法可靠处理时阻止计划。
- 只读 SQL 预览、复制/导出、写前漂移检查、结构快照、顺序执行/停止、逐步结果、重新比对及持久化执行记录。

# Non-goals

数据行比对/同步、任意 SQL 编辑执行、整库迁移、重命名猜测、整表删除或 DROP 后重建、外部表自动修改、自动回滚、发行安装包、全局工具升级、现有业务库操作。

# Acceptance examples

- A1：左右方向正确标明读取端与写入端，不同名配对保留目标表名；初次不全选，过滤全选仅作用于可见可执行项，跨类别保留选择；连接/库表/方向/选区变更或刷新使旧计划不可执行；同一物理表不得对自身同步。
- A2：隔离 MySQL 样本中，普通字段属性及顺序、普通/唯一/主键/全文/空间索引和常规表属性生成准确新增/修改/删除 SQL；仅改变选区及明确纳入的依赖；整表对齐遇不支持项阻塞，删除、缩窄、转换、NOT NULL/唯一性风险可见。
- A3：确证目标缺表时可创建保留目标名称的受支持表，源缺表不生成 DROP TABLE；特殊语法、权限不明、外部依赖无法确认时阻止相关计划并保留定义，不自动改外部表或关闭约束。
- A4：基本触发器可新增/替换/删除，保留 DEFINER、sql_mode 和字符集/排序上下文；只定位所属目标表，不全文改写正文；不能可靠保留顺序/上下文或有名称冲突时阻塞；含分号正文完整执行。
- A5：预览包含目标、摘要、关联操作、风险及完整 SQL，复制/原生导出完整，不能编辑任意 SQL；一次摘要确认覆盖破坏性条目；执行前两端漂移检查或原结构/初始记录保存失败时零写入。
- A6：只执行原生端当前计划，防重复提交并锁定上下文；顺序执行、失败停止，成功/失败/未执行分开；停止在语句边界生效，断线或进程异常标结果待核实且不自动重试，不承诺多条 DDL 整体回滚。
- A7：执行后重新比对，区分语句执行和结构复核结果；记录跨重启保存别名/库表/方向/时间/SQL/原结构/逐步结果，异常退出未完成步骤标待核实；可过滤、查看、导出，不能重放旧计划；不保存密码、完整连接串或业务行数据。
- A8：D1/D2 回归、前端/原生构建及规则/桥接/异步测试通过；隔离 MySQL 和真实 Qt WebEngine 覆盖选择、预览、确认、执行、记录及复核，窄窗口/主题/密度下主动作可达；Windows/macOS 最低系统未实测明确 NOT RUN。

# Constraints and invariants

只在测试创建的临时 loopback MySQL 实例验证写入，不接触现有数据库。保留 TLS、凭据隔离、后台任务和迟到结果隔离。原生端持有计划，前端不提供执行 SQL。原结构不是数据备份，不承诺无锁或两端统一快照。沿用锁定工具及平台待办，兼容声明仅限实测版本。

# Decisions

- Comet Native，当前干净 main 工作区。计划与执行生命周期紧密关联，保持单个 change，不拆 Supervisor。
- 用户明确确认完整 Shape，按本范围与 A1-A8 进入 Build。
- 基本触发器保留原 DEFINER，不新增切换为当前用户的选项；权限不足明确报错。
- 特殊对象仅展示；整表对齐不能跳过不支持项后宣称完整。

# Open questions

无待澄清项；用户已确认完整范围与验收。

# Verification expectations

复用 C++/前端测试、临时 MySQL 8.0.46 及真实桌面工具；补充正常、漂移零写入、失败停止、未知结果、存储失败和重启恢复证据。故障注入用于生命周期，不替代真实 SQL 证据。Builder 独立只读复核后交新 Verifier 验收，未运行平台保留限制。
