# D3 单表结构同步

## Purpose

新增 F10-F12、F20 和执行相关 F22，承接 D1/D2。D2 读取接口继续只读，本 capability 提供显式结构写入。验收统一使用 brief.md A1-A8。

## 方向与选区

固定左右位置，默认左到右，始终显示读取端和写入端，一次计划只写一端。不同名配对保留目标表名；同一物理表禁止自身同步，身份无法确认时保守阻止。

初次不全选，跨类别保留选择；过滤全选只选择当前可见可执行对象，显示总选数和可见数。受限项保留原因。整表对齐列出全部增改删，不能跳过不支持项后作为完整计划执行。

连接配置、库表、方向、选区改变以及刷新/取消比对均使旧计划失效；重启不恢复可执行计划。原生端绑定身份、配置修订、比对代次、选区和定义上下文；前端仅提交标识及操作，不提供任意 SQL。

## 支持范围

普通字段支持类型/长度精度、NULL、默认值、字符集/排序规则、注释、自增、可见性及顺序。索引支持普通、唯一、主键、全文、空间及其列顺序/前缀/排序/可见性/注释。表属性支持注释、默认字符集/排序规则、行格式。能力不足或定义无法可靠解释则阻止对应操作。

外键、CHECK、生成列、函数索引、分区、引擎转换及未知特性仅展示原定义。无关常规项可独立选择，但无法证明依赖安全则阻止相关计划。完整对齐及建表须完整支持，不静默丢弃特殊对象。

检查字段、索引、自增、约束、触发器及入向外键等依赖。必要本表关联操作先解释原因，由用户纳入后重新生成；不暗中扩选、不修改其他表、不禁用约束或触发器。依赖可见性无法确认时禁止有风险计划。

源存在且目标确证缺失时建表，保留目标库表名，不复制源 AUTO_INCREMENT 当前计数。源缺失不给出整表删除；不 DROP 后重建，不猜重命名。标识符安全引用，不全文改写引用、注释和字符串。

## 基本触发器

新增/替换/删除保留原 DEFINER、sql_mode、character_set_client、collation_connection 与数据库排序语义。无法满足上下文则阻止；不静默改用当前用户。所属表定位目标表，正文外部引用保持原文。

检查目标库名称冲突及同事件/时机顺序；顺序无法重现时仅展示。完整触发器通过协议发送，不按分号拆割正文；导出脚本使用适合客户端的分隔符，DELIMITER 不发送给服务器。替换的 DROP/CREATE 分别记录，创建失败不能掩盖删除已发生。

## 预览与写前检查

布局 B 主区底部预览，窄窗口可返回差异。显示目标别名/库表/方向、增改删数、完整 SQL、步骤语义、关联操作、风险与限制。SQL 只读，可复制和原生 UTF-8 导出；保存失败可见，取消不报错。

删除、缩窄、转换、NOT NULL/唯一性、自增、字符集转换、重建/锁等待风险明确提示。一次执行摘要确认覆盖全部破坏性条目，按钮明确到左/右侧，防重复提交。

执行前重新读取两端结构和上下文，核对身份/修订/代次，仅忽略已确认无关的自增计数等噪声。漂移或读取不完整则零 DDL。写前持久化两端原结构、SQL、初始记录，保存失败则零写入。原结构称原始结构定义，不称完整备份。

## 执行生命周期

后台隔离任务保持 TLS 和凭据规则；执行中锁定上下文，窗口仍响应，关闭时提示运行任务。顺序执行已确认原生计划，每步持久化开始及结果。

失败立即停止后续语句，分列成功/失败/未执行。请求停止在语句边界生效，显示等待当前操作结束，不承诺中断服务器当前语句。断线、超时、子进程丢失或异常退出无法确定结果时标待核实，不自动重试/继续。记录写入失败停止后续步骤并保留已知结果。

多条 DDL 不保证整体回滚，原 DDL 无法恢复丢失数据；写前检查不能保证检查与执行间没有外部并发变化。

## 复核与记录

结束或部分失败后尝试重新比对，语句成功与结构一致分别显示；部分选区允许仍有未选差异。复核失败标待核实，恢复连接后由用户重新比对，不重放计划。

执行记录入口按时间/状态/连接过滤。跨重启保存别名、库表、方向、时间、模式、摘要、SQL、原结构、步骤结果及脱敏诊断。异常退出未结束步骤标待核实。不保存密码、完整连接串或业务行；DEFINER 作为结构属性保留。

报告和 SQL 原生导出；重新比对回到对应工作台，连接已删除/改变时要求重新选择。历史记录不冒充实时状态，不提供直接重放。

## 验证与边界

只在独立临时 loopback MySQL 实例写入样本。复用锁定工具与 D1/D2 测试，补齐真实执行、漂移零写入、失败停止、停止/未知结果、记录失败、重启恢复及真实 Qt WebEngine 证据。

Windows 10/macOS 15 最低系统延续已有待办，NOT RUN 不作通过；本机通过仅代表本机。无数据同步、SQL IDE、整库迁移、自动回滚、发行包或全局升级。
