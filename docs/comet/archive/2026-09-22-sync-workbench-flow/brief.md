# Outcome

让用户快速将测试库中的表结构或数据同步到正式库。工作台以完成同步为主线，减少寻找入口、重复选择和理解内部术语的成本。

# Scope

- 顶部统一选择来源连接/库与目标连接/库；默认左端为来源、右端为目标，方向只在共享区域设置。
- 左侧使用 Ant Design 搜索和扁平 Tree 选择来源表，无重复数据库父节点；目标默认同名，不同名目标映射与刷新继续可达；来源表仅从清单搜索选择，不提供手动输入。
- 中间围绕当前表切换表结构/表数据，结果区优先，详情按需展开。
- 数据模式将准备键字段与扫描串为一次“开始比对”；默认可靠键、兼容字段和全表范围可见，条件调整保留独立草稿。没有可靠键时不自动退为可写比对。
- 右侧上方集中表结构/表数据、三个同步方式 Segmented、比对与预览按钮。原值行下展开，预览原位展示并返回差异；运行状态与停止全局可达。
- 一次只处理一张表，完成后保留两端连接并切换下一张表。

# Non-goals

- 不将本次产品设计请求视为连接或写入真实正式库的授权。
- 不增加与同步主流程无关的功能，不替换 Qt、React 和 Ant Design 技术栈。
- 不提供多表批量同步。

# Acceptance examples

- A1：工作台始终显示实际来源及目标连接、库和当前表；结构与数据共用一个方向，调整方向后旧计划失效，预览与最终确认的写入对象一致。
- A2：用户主动载入库表后，可在左侧搜索并通过无数据库父节点的 Ant Design Tree 单选来源表，默认配对目标同名表并可修改为不同名；来源无手动输入入口，搜索无匹配时显示未找到；切换下一张表保留两端连接与库、清理旧结果和计划。不依据清单缺项推断目标表不存在。
- A3：结构模式保留对象选择、全部对齐及原始定义；数据模式一次点击开始比对完成键字段准备和扫描，不要求单独点击读取键字段，不要求先测试连接。全表默认范围可见，无可靠键时明确阻止差异同步并保留独立浏览入口。
- A4：当前表的结构与数据结果区域优先显示差异，通过 Ant Design Table 行下展开完整原值，保留分页、定位、条件草稿、取消与应用行为；列表筛选不冒充同步范围，未知/失败/不完整结果不显示为相同。
- A5：上方用 Ant Design Segmented 常显两种比对内容及三个同步方式，比对与预览相邻。一个预览动作生成并原位展示真实计划，返回保留差异阅读状态，包含目标、范围和增改删摘要；保留结构选中对象/整表对齐、数据补齐/合并/完全对齐。数据默认补齐不变，合并更新同键差异，完全对齐涉及删除时额外确认；零变更不可执行。
- A6：执行前保留一次目标与变更摘要确认；执行中上下文锁定、停止入口可达、关闭预览不取消任务；执行后显示成功/失败/部分完成/待核实及重新比对入口，不自动执行下一张表或另一种同步模式。
- A7：在1920×1080桌面窗口中，来源目标、当前表及主操作可达，差异表内部滚动，无页面级横向溢出；选表入口可达，长库表名可查看完整值，键盘标签与焦点可用。
- A8：主题、密度、连接管理、执行记录、复制/导出及既有失效、精确值、冲突与提交边界保持；既有相关测试及前端构建通过，模拟交互证据与未运行的真实数据库验证分开记录。

# Constraints and invariants

- 保留已有防误写、结果失效处理和错误反馈。
- 桌面操作优先，使用 Operate 模式，以扫描效率和任务完成效率评价设计。
- 当前代码使用左侧/右侧连接，结构与数据各有工作台和执行面板；设计不能将未支持能力描述为已实现。

# Decisions

- 本轮用户要求顶部结合原版，恢复两端各自的连接选择、测试、编辑和测试结果；中间保留对换。用户后续明确删除来源手动表名入口；只搜索、选择清单中的来源表，空结果显示未找到，无手动替代。

- 用户将桌面适配和验收基准调整为1920×1080，不再要求1440×900与1024×768专项适配；其余方案无异议。

- 用户明确现有布局存在操作障碍，核心任务是测试库向正式库同步表或数据。
- 用户确认“一次一张”，以单表闭环和连续切换为设计基础。
- 用户要求实施前先看 Impeccable 画面；独立交互原型位于 docs/design/single-table-sync/index.html，使用示例数据，不代表用户已确认 Shape 或授权进入 Build。
- 用户认可原型并要求顶部来源与目标之间增加“对换”按钮。对换连接、数据库与表映射，清空旧结果与计划后重新比对；在途任务期间禁用。本轮先更新原型，未进入业务实现。
- 继承现有 Ant Design 组件、蓝色主操作、系统字体及浅深主题；本次重组工作台流程，不更换产品视觉身份。
- 中间 C 稿的顶部选表、固定底栏、侧边详情及预览抽屉已被末轮 Ant Design 原型覆盖。此前规格漏同步导致实现偏离，用户本轮明确指向最后确认的原型，按该设计修正；保留1920×1080和全部实际执行保护。
- 保持已有数据默认补齐策略，合并与完全对齐可显式选择；不因“快速同步”隐式增加更新或删除范围。
- 启动应用不自动连接或扫描；用户载入清单和开始比对才发起相应读取。
- 单表流程涉及同一组工作台组件，保持单一 change，不拆 Supervisor。
- 当前工作区干净且没有 active change，使用当前目录创建单一 Native change。
- 先确定任务范围，再形成可确认的完整方案；尚未进入 Build。
