# 目标

优化比对工作台顶部「来源连接 / 目标连接」连接区（`.connection-bar`）的布局：修复对换按钮悬浮错位、标题与详情层级混乱、纵向占用过高的问题，使连接区作为上下文信息保持可扫读，不抢占下方比对内容的视觉优先级。

现状问题（来自截图与代码核查）：

1. `Typography.Title level={5}` 的「来源连接 / 目标连接」标题视觉过重，占据大量纵向空间。
2. `.connection-bar` 使用 `align-items: center` 的三列网格，两侧内容高度不一时，「对换」按钮垂直居中悬浮，与它实际操作的对象（两侧连接选择）没有对齐关系。
3. `.endpoint-detail` 纵向堆叠主机行、测试结果行、独立成行的时间戳（`.test-result time { flex-basis: 100% }`），三行 12px 文本参差不齐。
4. 整条连接区约 130px 高，相对其信息密度过高；连接区是上下文而非当前任务。

# 范围

- `frontend/src/main.tsx` 中 `endpoint()` 渲染的连接区结构及 `ResultText` 组件。
- `frontend/src/style.css` 中 `.connection-bar`、`.endpoint`、`.endpoint-controls`、`.endpoint-detail`、`.test-result` 及相关响应式规则。
- 浅色与深色主题下的表现均需正常。

# 非目标

- 不改变连接选择、测试连接、编辑、对换、新建的功能行为与数据接口。
- 不改动「连接管理」页面、「选择数据库」抽屉及下方数据库/表选择区。
- 不引入新的第三方组件库或自制设计体系，继续以 Ant Design 组件为主体。
- 不改变连接测试失败时的反馈渠道（失败仍需 message 提示 + 区域内结果展示）。

# 验收示例

- Scenario: A1 连接区单行化
  - WHEN 打开比对工作台并查看顶部连接区（任一状态：未选连接 / 已选连接 / 测试进行中）
  - THEN 每侧呈现「来源/目标 行内标签 + 连接选择器 + 测试连接按钮 + 编辑按钮」的单行控件组，不再渲染独立的大标题行；来源/目标角色标识始终直接可见，不依赖颜色或悬停。

- Scenario: A2 对换按钮对齐
  - WHEN 两侧详情高度不一致（例如一侧测试失败带长错误文案、另一侧成功或未测试）
  - THEN 对换按钮与两侧控件行对齐（顶部与控件行同一起线），不再垂直悬浮于整条栏的几何中心。

- Scenario: A3 状态行合并
  - THEN 每侧的主机地址、测试结果标签与原因、测试时间合并为一个紧凑状态区：时间戳不再独立占一行；长错误文案可自然换行但保持完整可读。未选择连接时该位置显示「尚未选择连接」次要提示；测试进行中显示既有「正在测试连接… 已用时 X 秒」文案。

- Scenario: A4 响应式与主题
  - THEN 在 1920px、≤1050px、≤750px 三档宽度下连接区无横向溢出；≤750px 时两侧堆叠为单列，对换按钮在堆叠视图中水平居中；浅色与深色主题下均正常渲染。

- Scenario: A5 回归不破坏
  - THEN `npm run build`（tsc --noEmit + vite build）与 `npm test` 全部通过；连接选择、测试、编辑、新建、对换的交互行为、禁用条件与现有 `aria-label`（来源连接/目标连接/选择来源连接/选择目标连接）保持不变。

# 约束与不变量

- 同步方向必须始终可见：来源/目标的角色标识不能弱化为仅靠颜色或图标暗示。
- 连接测试失败时，失败原因文字在界面上保持可读（不被默认折叠或隐藏）。
- 键盘与读屏可达性不回退：现有 `aria-label` 保留或等价保留。
- 窄窗口（≤750px）下不出现横向溢出，现有响应式降级行为需保持或改善。
- 遵循项目现有 4px 基准间距与 Ant Design token（colorPrimary #2764d7、borderRadius 6、fontSize 14）。
- 按钮图标遵循 `button-icons` 能力规格（测试连接 ApiOutlined、编辑 EditOutlined、对换 SwapOutlined 等），按钮文案不变。

# 决策

- D1（用户已确认）：采用方案 A「单行紧凑工具栏」——去掉大标题，来源/目标降为控件行内的行内标签；对换按钮与控件行对齐；主机、测试结果、时间合并为每侧一行紧凑状态区。备选的 B（保留两栏标题精修）与 C（连接芯片化，失败原因收进弹出面板）被否决，C 另因违背「失败原因保持可读」约束出局。
