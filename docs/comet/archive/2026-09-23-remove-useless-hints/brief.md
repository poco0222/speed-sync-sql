# 目标

去掉界面中无用的说明性文案，降低阅读噪音。按用户确认，移除四类：重复的范围/筛选声明、教学式使用引导、历史记录免责文案、技术细节解释；同时删除无引用的设计原型文件 `frontend/src/prototype.tsx`。

# 范围

`frontend/src` 下 7 个文件的用户可见说明文案与 1 个无引用文件：

- `SchemaWorkbench.tsx`：移除"差异优先 · 查看筛选不改变同步范围"、空状态引导段、DDL 页签解释段、映射抽屉引导段、比对进行中 Alert 的"后台执行，可取消；两端分别读取，不保证统一快照。"描述。
- `SyncPanel.tsx`：范围声明精简为"范围：整张表 / 已选 N 项"；"正在检查依赖并生成计划，不执行写入。"去掉"不执行写入"；移除"SQL 与技术说明"内解释段；结构复核 Alert 仅在出错时显示描述。
- `DataWorkbench.tsx`：移除"默认全表范围；开始比对自动采用可靠键与兼容字段…"、条件抽屉"取消保留当前结果…"提示、读取一致性详情中"两端各自快照，不代表全局同一瞬间。"；计数行精简为"当前查看共 N 条 · 本页 N 条"；记录详情段精简为仅状态标签。
- `DataMergePanel.tsx`：同步摘要段仅保留状态/预计，移除模式行为声明与"范围外记录保留。查看筛选不改变写入范围。"；移除预览顶部整段范围声明；"完成可靠键比对后可预览；无键浏览、停止或失败的扫描不能写入。"缩短为"完成可靠键比对后可预览。"；移除"源扫描快照为基准…"与"执行结果不等于复核一致…"两处解释。
- `SyncRecords.tsx`：移除"历史记录不代表实时结构或数据…"、"批次结果不代表数据已完全一致…"、"仅结构定义，不含业务数据，不能恢复已删除数据。"。
- `main.tsx`：移除连接页"保存配置与测试连接相互独立。"与端点详情"选择已有连接或新建连接；测试连接可选"。
- 删除 `frontend/src/prototype.tsx`（无任何引用）。

# 非目标

- 不改变按钮、表头、状态标签、计数、目标/范围/条件摘要等承载操作与结果的信息。
- 不移除执行确认与删除确认弹窗中的风险警示、错误/警告 Alert、表单字段提示（extra）、needsScan 等状态反馈。
- 不修改后端 C++ 代码与其返回文本；不调整布局、交互逻辑与视觉样式。

# 约束与不变量

- 保留仍有信息量的内容：状态（执行中、生成计划、错误、禁用原因"完成可靠键比对后可预览"）、计数、"未参与"字段清单、读取时间与一致性数值、needsScan 反馈。

- 现有前端组件测试（frontend/tests）不因文案变更而失配；如断言涉及被删文案需同步更新。
