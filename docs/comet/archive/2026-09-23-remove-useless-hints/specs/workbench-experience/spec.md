# 单表同步工作台

## 目的与边界

帮助用户将测试库的一张表结构或表数据同步到正式库。一次只处理一张表，完成后保留连接和数据库以便切换下一张。采用 Operate 模式，以任务完成和差异阅读为优先。验收统一引用 brief.md A1–A5。

保持 Qt 桌面容器、React、Ant Design、现有浅深主题与密度。产品中的来源/目标表示用户选定的读写角色，不通过连接名称猜测环境。本次不提供多表批处理、自动连续写入、结构与数据联动执行或新数据库引擎。

## 布局与选表

来源和目标之间提供可见的“对换”按钮，同时互换连接、数据库和当前表映射。对换后清空旧比对结果和计划，重新比对才能预览同步；比对或执行在途时禁用对换，不能只互换画面标签而保留旧方向。

顶部紧凑区域集中显示来源连接/数据库和目标连接/数据库，两端各自常显连接选择、新建/编辑、可选测试及独立的测试中/结果反馈，中间保留对换。数据库选择与载入保留次级入口。方向仅在该区域设置，默认原左端为来源、原右端为目标；保留显式反向能力，结构和数据使用同一方向，不能各自持有互相矛盾的方向。

左侧约220px区域提供 Ant Design Input.Search 和 Tree，直接平铺来源表名，不显示重复数据库父节点。选择来源表默认配对目标同名表，次级入口允许手动指定不同名目标。来源表仅从已载入清单搜索选择，不提供手动输入或“使用此表名”入口。未载入时提示载入，搜索无匹配时显示未找到。数据库与不同名目标映射仍可输入；清单只代表账户可见对象，缺项不能证明对象不存在。刷新入口可达。启动不自动连接，用户主动载入库表后读取清单。

右侧显示当前表，上方使用 Ant Design Segmented 常显表结构/表数据及三个同步方式，比对与预览按钮相邻；其下显示目标、范围、摘要和差异。保留单侧来源表树，不提供宽度滑块，不使用固定底部主操作栏。运行状态及停止入口全局可达。连接管理、设置和执行记录作为次级功能继续可达。

以1920×1080桌面窗口作为适配及验收基准，不要求1440×900和1024×768专项适配。结果表内部滚动，页面不横向溢出，长连接/库表名可以查看完整值。控件保留标签、键盘焦点和非颜色状态反馈。

## 说明文案边界

界面不常驻显示解释性、教学式或免责说明文案：不出现“查看筛选/筛选不改变（同步/写入）范围”“页面筛选、键定位与分页不缩小写入范围”“范围外记录保留”“不受列表筛选影响”类范围声明，不出现连接与比对入口的使用教学（如“无需先测试连接”“保存配置与测试连接相互独立”“默认全表范围；开始比对自动采用可靠键与兼容字段”），不出现历史记录与结果的免责文案（如“历史记录不代表实时结构或数据”“批次结果不代表数据已完全一致”“仅结构定义，不含业务数据”），也不在预览与详情中常驻技术解释（如“预览不写入”“多条 DDL 不保证整体回滚”“源扫描快照为基准”“两端各自快照，不代表全局同一瞬间”）。

仍保留的信息与反馈：状态与进度（执行中、正在生成计划、正在检查依赖并生成计划、错误与警告 Alert）、计数与摘要（已选 N 项、当前查看共 N 条 · 本页 N 条、本次预计、已确认提交 N / N）、生效条件摘要（键、参与字段、共享 AND 范围/全表）、“未参与”字段清单、读取时间与一致性数值、needsScan 失效反馈、按钮禁用原因的最短形式（“完成可靠键比对后可预览”）、Empty 与表格自身的状态描述及表内回退文案、表单字段 extra 提示。

执行前确认（结构执行、数据写入、完全对齐删除勾选）中的目标身份、变更摘要与风险警示完整保留；安全边界由确认弹窗与后端校验传达，不依赖常驻说明文案。`frontend/src/prototype.tsx` 设计原型文件删除，源码不再包含无引用原型页。

## 比对入口

表结构模式直接使用现有比对能力，保留字段、索引、约束、触发器、表属性和原始定义的访问。结构默认显示差异，相同对象及可能作为关联操作的对象可以切换查看和选择。

表数据模式将准备可靠键和兼容字段、使用生效范围启动扫描串联为一次“开始比对”，默认采用后端返回的可靠键与兼容字段，不创建新的匹配推断。无可靠键时停止可写比对流程，显示原因并提供显式独立浏览，不把未匹配记录当作已确认差异。准备或扫描失败可重试，不重复启动在途请求。

用户可在次级条件入口调整匹配键、参与字段和类型化共享 AND 条件。首次配置所需的元数据读取由该入口完成，不要求用户理解“准备”阶段。条件草稿与生效配置分离；取消保留结果，校验成功后才应用，无变化不失效，有效修改后清理旧结果与计划并提示重新比对。保留现有类型化条件，不新增任意 SQL 输入。

## 差异阅读

完整可靠键比对默认显示 different、left-only、right-only，仍可查看 same 或 all，保留完整键定位和服务端分页。全局计数、当前查看数量和扫描条件分别表达。查看过滤、定位和分页不改变扫描或写入范围。未完成、失败、取消、无可靠键和不支持状态不可显示为相同。

主表以“目标现在 / 同步后（按当前方式）”展示预计结果，并标注保持原样的差异；预计结果不代替真实执行计划。顶部操作下显示“本次预计”摘要，显示目标、范围及新增/更新/删除/保留计数；切换同步方式后同步更新。Ant Design Table 点击行或键盘展开按钮在该行下方显示详情，集中展示记录标识、变化字段、来源原值、目标原值和预计结果；不使用侧边详情，上下文变更清理旧详情。变化属性优先，完整信息按需展开。详情保留 NULL、空串、零、缺失的区别，以及精确数、长值分块、原文/HEX复制、导出、错误反馈和代次保护。收起详情保留列表筛选、页码和定位。

## 同步预览与执行

结构提供仅新增、新增+更新、完全对齐（含删除）三个常显方式，映射到现有选中对象/整表对齐规划能力：仅新增预选来源独有对象，新增+更新预选来源独有与不同对象，完全对齐覆盖整表；选中对象方式仍可调整选区，依赖检查由真实规划负责。整表对齐明确包含全部增改删，不因列表过滤而缩小。数据保留补齐、合并、完全对齐，默认补齐不变：补齐仅插入缺失记录，合并还更新同键差异，完全对齐还会删除范围内目标独有整行。源目标身份和模式摘要在预览前可见。

“预览同步”直接调用现有规划能力，在右侧内容区原位展示真实计划；差异内容隐藏但保持挂载，“返回差异”恢复筛选、页码及展开状态，不使用预览抽屉。预览显示实际计划中的目标连接/库/表、方向、范围、键与字段、增改删计数及明细。SQL、读取时刻和一致性数值按需展开；影响本次执行的风险与阻塞直接显示。零变更不允许执行。数据查看筛选和分页不缩小计划范围，不新增单行勾选写入能力。

执行只使用当前有效计划，执行前保留一次目标与变更摘要确认，涉及完全对齐删除时保留额外删除确认。预览不自动执行。保持参数化 SQL、结构漂移及目标旧值检查、DDL不能整体回滚、数据分批提交、副作用提示与停止边界。

## 生命周期与结果

来源、目标、数据库、表、方向、生效条件和选区变化须经过既有失效链；迟到响应不能恢复旧结果或计划。切换下一张表保留连接/库但不沿用旧计划。结构与数据写入互斥，写入期间锁定上下文；读取可取消，不能重复提交。

关闭预览只隐藏 UI，保持任务挂载、状态轮询和全局锁，运行状态及停止动作持续可达。结束后区分成功、失败、部分提交、回滚、未执行、待核实及复核结果。结构继续使用既有执行后复核，数据提供重新比对入口。不得自动重试待核实写入，不自动执行下一张表。

## 验证

复用既有规则、分页、生命周期及桥接测试，对说明文案移除补充渲染断言，执行前端构建，并在1920×1080桌面尺寸验证结构与数据的完整模拟流程和错误状态。模拟桥接仅存在于验证路径。真实数据库、桌面平台与生产写入未验证的部分单独报告，不以历史验收代替当前证据。
