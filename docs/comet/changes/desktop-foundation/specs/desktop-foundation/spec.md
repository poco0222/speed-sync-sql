# D1 桌面与连接基础

## Purpose

为 Speed Sync SQL 建立真实的 Qt 桌面应用和左右两端 MySQL 连接能力。继承产品规划的布局 B、中文界面与 Ant Design 组件体系。本 capability 只定义 D1，不提前实现结构/数据比对或同步。

## 平台与工程

- 最低目标：Windows 10 1809+ x64、macOS 15+ arm64。Windows ARM、32 位、Intel Mac 不在本轮构建矩阵中。
- 固定 Qt 6.10.2、React/react-dom 19.2.7、TypeScript 6.0.3、Ant Design 6.4.5；其余前端构建依赖选兼容版本并由锁文件固定。
- 使用 CMake/Ninja、C++20；Windows 为 MSVC 2022 x64，macOS 为 Apple Clang。先复用现有 DevTools 工具，记录实际构建版本。
- 工程分为原生桌面端、前端、相关测试及构建说明。构建产物、依赖与缓存留在项目约定目录；不新增远程业务服务。
- Qt WebEngine 加载本地构建资源，正式运行不依赖前端开发服务器或外部 CDN；所需 WebEngine 资源、辅助进程和插件路径均有说明。
- 产品最低系统与构建机器系统分开记录；设置 macOS deployment target 为 15.0，不能据此宣称已经完成最低版本实测。

## 原生外壳与桥接

- 使用真实 Qt 窗口，保留平台原生窗口按钮和系统菜单习惯。启动进入工作台；无配置时直接引导添加连接。
- React 通过 WebChannel 调用原生应用接口；原生端负责连接存储、平台凭据、数据库连接测试和文件保存。
- 请求携带可关联的标识，返回成功、失败及真实任务状态。前端校验用于交互，原生边界重复校验输入，不信任网页传入的路径或参数。
- 限定受信本地应用页面访问桥接；外部导航不得获得数据库或凭据接口。桥接不可用时明确显示不可用状态，不回退到假成功数据。
- 数据库连接在工作线程内建立、使用与释放，不能跨线程复用 QSqlDatabase 或阻塞窗口事件循环。
- 原生保存使用系统保存对话框。D1 通过导出脱敏连接测试摘要提供实际使用入口；用户取消不报错，写入失败保留错误原因，不导出密码。此功能不提供 SQL 执行或数据库备份。

## 连接管理

- 支持新增、编辑、复制、删除、测试、保存，以及用作左侧或右侧。两端使用固定位置与独立状态。
- 基本字段：名称、主机、端口（默认 3306）、用户名、密码、可选默认数据库。名称/主机/用户名必填，端口须为 1-65535 整数；密码可为空以支持合法无密码测试账户。
- 高级参数包括连接超时及 TLS。TLS 明确区分优先加密、要求加密、验证服务器身份、关闭；默认优先加密。验证服务器身份需校验 CA 和主机名；不支持的选项必须报错，不静默降级。详细驱动选项以 Qt 6.10.2 与实际客户端库核验结果为准。
- 连接超时默认 10 秒，用户可设 1-60 秒；文案区分连接超时与整个任务结束时间，不承诺可即时中断操作系统 DNS 或客户端库内部阻塞。
- 保存与测试独立；网络不可达不妨碍保存合法配置。测试失败不清空表单；编辑连接参数即使测试正在进行，也使旧结果失效。
- 复制创建新连接身份和名称，不直接继承密码或凭据引用。删除连接配置提示不影响数据库，删除后清除其两端选中状态与对应凭据。
- 非敏感连接元信息在原生应用数据目录持久化。写入失败向用户反馈；损坏配置不能被静默覆盖为空配置。
- 连接列表显示最近测试时间和结果，使用“上次测试成功”等文案，不能把保存配置或历史成功显示为实时在线。

## 密码

- “记住密码”默认关闭。未勾选时仅在当前应用会话中使用，退出后不恢复；前端持久化存储、普通配置及诊断日志均不存密码。
- 勾选后通过 Windows Credential Manager 或 macOS Keychain 保存，以稳定连接 ID 关联；界面不回显已保存密码，只表示已保存，并允许替换。
- 取消记住或删除配置时清理平台凭据。读取、保存或清理失败须明确提示，不假报完成，不退回明文保存。
- 测试错误和诊断摘要不得含密码、完整凭据串或带密码的连接 URL。

## 连接测试

- 用真实 QMYSQL 驱动建立短连接，成功读取服务器版本和当前数据库等最小信息后关闭。不读取业务表，不执行 DDL/DML。
- 目标为 MySQL 8.0+；检测到低版本或非目标数据库时标记不支持，而非宣称可进行后续比对。不能对未经验证的所有未来版本作兼容承诺。
- 区分插件缺失/加载失败、认证失败、网络不可达或超时、数据库不存在或无权限、TLS 失败以及无法进一步分类的连接错误。分类以实际驱动错误为依据，不猜测服务端原因。
- 同一端测试期间防重复提交，另一端可独立操作。请求结束后恢复可操作状态；已失效、已删除或参数已变化的连接不能被迟到结果标为成功。
- 测试中显示真实忙碌状态与耗时，不伪造百分比；窗口仍可移动、操作非冲突区域。
- 关闭窗口时有运行任务须提示，等待任务有界结束并释放线程/连接，不直接销毁仍在运行的线程。

## 框架与设置

- 使用 Ant Design Layout/Menu、Drawer/Form、Table、Alert、ConfigProvider 等标准组件；保留顶部左右连接区和对照工作台轮廓。
- D1 提供工作台、连接管理与设置。未实现的表导航、数据模式、执行记录、同步按钮隐藏；空工作台说明先配置连接，不显示假的差异或成功结果。
- 主题支持跟随系统、浅色、深色；密度支持标准与紧凑；设置本地持久化，连接超时可由连接高级选项覆盖。
- 复用已确认的中性灰/蓝色主操作、系统字体与语义状态配色；不添加营销动画或统计卡片。
- 在 1440×900、1280×800、约 1024px 宽及高缩放下检查连接表单、错误文案和关键按钮。长名称与错误可换行或滚动，不能挤走操作。
- Tab 焦点顺序可用，表单标签明确，密码默认隐藏，状态同时有文字；平台复制等快捷键符合 Ctrl/Cmd 习惯。
