# 桌面任务状态与实例隔离

## Purpose

补齐已交付桌面工作台的状态一致性和记录恢复边界，验收采用 brief.md A1–A5。

## 写入状态

数据写入（含启动确认到运行结束）独立于只读扫描上报，执行期间连接、库表、设置、历史恢复及其他会丢失当前上下文的入口禁用。主状态栏明确显示数据写入。保留查看执行进度与请求边界停止；结束后解锁。原生继续校验上下文与任务互斥；只读扫描可取消或通过切换连接失效，迟到结果不回填。

## 设置保存

主题、密度与默认连接超时保存不销毁当前数据扫描结果或计划；外观立即生效，默认超时影响后续建立的连接，不更改在途请求。写入时设置禁用。设置后的详情、分页、预览与执行继续使用同一完整扫描，不显示伪有效结果。

## 同目录单实例

共享配置目录在任何配置读取、临时清理和执行记录恢复之前获得排他 QLockFile，并持有到 Foundation 销毁完成。占用或存储失败给出明确错误，拒绝后续原生操作，不改变任何共享记录或配置。不同配置目录独立运行。正常退出释放；异常退出后仅取得目录锁的实例可将旧 running 执行标记 unknown，保留已有提交计数且不自动重试。

## 验证边界

测试使用隔离配置目录、现有生命周期 fixture、临时 MySQL 和真实 Qt。只读扫描、结构同步、数据补齐/合并/对齐、异常恢复回归。最低目标系统与远程发行维持原待办。
