# 连接区单行紧凑布局规范

## 目的与边界

重构比对工作台顶部「来源连接 / 目标连接」连接区（`main.tsx` 的 `endpoint()` + `style.css` 的 `.connection-bar` 系列样式），解决标题过重、对换按钮悬浮错位、状态信息三行堆叠的问题。本能力只约束连接区的结构与视觉布局，不改变连接选择、测试、编辑、新建、对换的功能行为、禁用条件和数据接口。验收统一引用 brief.md A1–A5。

「连接管理」页面、「选择数据库」抽屉、数据库/表选择区不在本能力范围内。

## 目标结构

连接区保持三列网格 `minmax(0,1fr) auto minmax(0,1fr)`，`align-items` 改为使对换按钮与两侧控件行对齐（而非整栏垂直居中）：

```text
来源 [连接选择器▾] [测试连接] [编辑]     ⇄ 对换     目标 [连接选择器▾] [测试连接] [编辑]
<每侧状态区：主机 · 测试结果 · 时间>                <每侧状态区>
```

- 每侧结构为「控件行 + 状态区」两行；不再渲染 `Typography.Title` 大标题行。「来源」/「目标」为控件行内的行内标签（小号加粗，普通文本色），同步方向始终直接可见。
- 对换按钮保持 `SwapOutlined` + 文案「对换」，顶部与两侧控件行同一起线；两侧详情高度不等时位置不变。
- 控件行内布局：标签（不换行、不收缩）→ Select（`flex: 1`）→ 测试连接按钮 → 编辑按钮；间距沿用 8px 基准。

## 状态区

- 已选连接：主机地址（mono 字体）与测试结果（Tag + 原因文字 + 时间）合并为一个紧凑行内流，`flex-wrap` 允许长错误文案自然换行；时间戳不再独立占行，以次要色小字号跟随结果之后。
- 未选连接：显示「尚未选择连接」次要文字占位。
- 测试进行中：沿用现有「正在测试连接… 已用时 X 秒，窗口仍可操作」文案。

## 样式与主题

- 间距使用 4px 基准的现有刻度；连接区整体纵向内边距相应压缩（目标高度约为原来的一半）。
- 颜色全部通过现有 CSS 变量（`--surface`、`--line`、`--muted`）与 Ant Design token 获得，浅色/深色主题无需单独硬编码。
- 清理因删除标题而失效的规则（如 `.schema-workbench > .connection-bar .ant-typography { margin-top: 0 }`）。

## 响应式

- ≤1050px：保持三列，收窄间距。
- ≤750px：降为单列堆叠（左侧、对换、右侧各占一行），对换按钮在堆叠视图中水平居中；控件行内 Select 换行占满整行（沿用现有规则）。

## 可达性与回归

- 保留 `section` 的 `aria-label`（来源连接/目标连接）与 Select 的 `aria-label`（选择来源连接/选择目标连接）。
- 按钮图标与文案遵循 `button-icons` 能力规格，不改变 `type`、`danger`、`loading`、`disabled` 语义。
- `npm test` 与 `npm run build`（tsc --noEmit + vite build）必须通过。
