# Speed Sync SQL 产品规划与设计

本目录是用户已确认范围的产品规划与设计交付，描述未来产品，不代表功能已实现。规划归档时项目只有工作流和文档；后续实现状态见 [项目 README](../../README.md)，验收状态以对应 Comet 报告为准。

建议依次阅读：

1. [总体产品方案](overview.md)：目标、23 项功能、结构与数据同步规则、非目标。
2. [功能可行性](feasibility.md)：技术依据、架构、运行边界与后续验证。
3. [页面布局与交互](interaction-design.md)：工作台、数据页、连接、预览、结果、视觉与 Ant Design 对应。
4. [后续开发路线](roadmap.md)：7 个独立开发阶段，均留给后续新 change。

[PRODUCT.md](../../PRODUCT.md) 保存用户已确认的产品事实。用户已选择 B「对照工作台」，并确认总体方案、模式与设计范围。确认设计不等于授权数据库写入或启动后续开发。

本次没有生成产品界面代码或高保真截图。页面交付为区域线框、交互状态与视觉规范；布局示例均为示例数据。后续实现应做双平台实际视觉检查。
