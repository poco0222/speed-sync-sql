# 工作台实现交互验证

2026-09-22，Codex 浏览器操作真实 React/Ant Design 组件，Vite 入口 `/tests/workbench.html`。桥接由 `frontend/tests/workbench-mock.mjs` 提供；页面明确标记隔离测试，没有连接数据库，执行仅改变内存状态。

## 已实际操作

- 1440×900：结构比对显示变化属性，展开 status 后 type、nullable、default、collation 按行左右对齐；完整对象 DDL 保留。
- 数据准备/扫描：默认全部差异。测试全局计数相同33、不同35、仅左5、仅右3；查看共43、本页30，表格内部滚动。
- 原值详情默认仅变化字段；取消勾选可见全部字段及精确数 `9007199254740993.01`。NULL 和长值缩略/加载入口分别展示；关闭回到当前结果。
- 写入预览默认补齐，显示真实测试目标、全表范围、键字段和新增5/更新0/删除0。最终确认再次展示目标、范围及分批提交风险。
- 确认内存模拟执行后关闭抽屉，外部运行状态和停止入口保留。切换结构标签时结构比对、导航库表及连接选择均禁用；重开预览仍显示运行中。请求边界停止后显示已停止，连接/条件解锁。
- 1024×768：条件草稿增加 `id = 1001` 并应用，旧结果消失，出现重新比对提示，生效摘要同步更新。
- 1024×768：共享导航可从两种模式恢复；展开导航后的结构表在自身容器内横向滚动。写入抽屉及条件抽屉操作可达。
- 初次窄窗口检查发现数据 Grid 的隐式最小轨道造成页面横向溢出，改为 `minmax(0, 1fr)` 后复测：普通页面 `scrollWidth=clientWidth=1009`；抽屉打开为1024；1440窗口普通页面两者为1425（滚动条占15px）。

## 自动化证据与边界

前端包含草稿取消/无变化/有效应用、迟到详情、详情关闭保留页码、关闭写入抽屉保留轮询锁、切换标签保留挂载与结构互斥的组件回归。原生 data-tests 覆盖差异分页 COUNT/SELECT 和复合键交集。

此记录是开发期交互观察，不替代 Comet 独立验收。真实 MySQL 写入、Qt WebEngine 实机窗口、Windows/Linux 平台未执行；不据模拟结果宣称这些验证通过。

## A4 验收缺陷修复复测

独立验收发现越界条件可提前清空旧结果；修复完整类型定义校验后，浏览器重新扫描43条差异，输入 `id = 18446744073709551616` 并应用：草稿保持打开并提示“整数筛选值超出字段范围”，原列表与分页仍保留。新增整数有符号/无符号边界、DECIMAL精度、小数位及BIT范围规则和组件回归。
