# D2 开发验证

日期：2026-09-15。环境：macOS 27 arm64、Qt 6.10.2、MySQL 8.0.46、Node 24.19.0；目标平台仍为 Windows 10 1809+ x64 / macOS 15+ arm64。

## 实现范围

库表显式加载与配对、五类元数据读取与结构化比对、原始表/触发器定义、可信的完整性状态、搜索/筛选、最近配对/宽度、可取消后台读取、原生 JSON 摘要导出。产品数据库路径只读，不提供同步 SQL 或数据行操作。

MySQL 测试覆盖异库异表同结构、自增计数忽略、字段/索引/约束/触发器/属性差异、生成列/不可见列/函数索引、分区、特殊标识符、列级权限、无触发器权限、单端缺表、双端缺表与视图。应用查询的 general_log 审计只允许元数据查询和驱动会话初始化；表与触发器定义前后不变。所有样本准备写入只发生在独立临时 loopback 实例，结束销毁。

桌面测试直接操作真实 Qt WebEngine DOM，与真实本地 MySQL 连通；检查恢复选择不自动比对、库表读取、类别切换、搜索无匹配不改变总体结论、双端原始定义、换表失效、相同表比对及重载不恢复旧结果。截图包括 1440×900、1280×800、1024×800，以及 deviceScaleFactor=2 的深色/紧凑布局；主动作位置检查通过。此为本机桌面证据，不等于目标最低系统实测。

原生异步测试使用单独测试可执行文件的可控子进程，验证取消后新任务、迟到结果隔离、编辑连接失效、窗口事件循环响应及超时回收；导出测试覆盖取消、完整行数、敏感连接字段排除及保存失败。模拟子进程结果仅用于生命周期测试，不作为数据库读取证据。

独立验收要求补齐 A2/A5 后，增加真实 FULLTEXT、SPATIAL 索引属性及具体 changed 断言；比较规则测试合计 36 项，含字段/索引逐属性变化矩阵、精度末位、NULL/字符串与索引顺序。桌面脚本实际切换“只看差异”并核对相同行隐藏、总体摘要不变；长表和触发器 DDL 双端展开，通过真实按钮复制并逐字核对系统剪贴板。复制改为 Qt 从当前比较缓存取原文，避免网页复制权限差异。

复制测试使用 macOS NSPasteboard 将全部项目/格式保存在辅助进程内存，结束或测试进程断开时恢复；不把原剪贴板内容写入日志或磁盘。Swift 测试辅助程序编译到项目 `.local/test-tools/`，不安装到全局目录。该复制审计目前仅在 macOS 运行。

桌面设置选择曾因弹窗动画期间计算点击坐标而偶发超时；驱动已改为键盘打开选项并确认选中值。报告启动即标 running，失败写 failed，不把旧的 passed 文件当作当前证据。

## 复核修复

- 普通注释/字符串/引用标识符中的特殊语法词不再误报不支持；真实版本注释内语法仍保留。
- 结构漂移指纹排除真实顶层自增计数选项，包含首次插入前后的缺省/显式边界；字段自增与其他定义内容仍参与核对。
- 搜索保留未读取/失败/不支持原因。
- 连接读取失败仍保留所选库表与起止时间，供界面及摘要定位。

- 角色/复杂授权、大小写配对歧义、分区与未知特殊选项保守标受限；没有冒充空集合或相同。
- 两端不是统一快照；表定义前后核对不能保证捕获所有外部并发变化。
- 不包含正式安装包、签名或干净机器发行验收。
